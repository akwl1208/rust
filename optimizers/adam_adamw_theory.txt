================================================================
 Day 44 : 옵티마이저 심화 — Adam & AdamW (이론 정리)
================================================================

코드(optimizers.py / main.rs)와 짝을 이루는 이론 정리본.

한 줄 요약:
  옵티마이저는 SGD(같은 보폭) -> Momentum(관성)
  -> Adam(파라미터별 보폭) -> AdamW(거기에 과적합 방지 decay)
  로 발전했고, 마지막 AdamW가 LLM 파인튜닝의 표준이다.
  튜닝 손잡이는 learning rate 와 weight decay 두 개.


----------------------------------------------------------------
0. 옵티마이저란?
----------------------------------------------------------------

손실을 줄이려고 '가중치를 어떻게 업데이트할지' 정하는 방법.
기본 뼈대는 경사하강법이지만, 어떻게 움직이느냐에 따라
SGD / Momentum / Adam / AdamW 로 나뉜다.

이번 회차의 큰 질문:
  "왜 LLM 파인튜닝은 AdamW를 표준으로 쓰는가?"


----------------------------------------------------------------
1. 출발점: SGD 와 그 문제점
----------------------------------------------------------------

SGD(확률적 경사하강법)는 가장 단순한 옵티마이저.
  업데이트:  p = p - 학습률 * 기울기

문제: 모든 파라미터에 '똑같은' 학습률을 쓴다.
  - 가파른 방향: 보폭이 너무 커서 좌우로 진동
  - 완만한 방향: 보폭이 너무 작아서 굼뜸
  => 방향마다 사정이 다른데 보폭이 하나뿐이라 비효율적.

이 한계를 극복하려고 나머지 옵티마이저가 발전했다.


----------------------------------------------------------------
2. Momentum: 관성 추가
----------------------------------------------------------------

이전에 움직이던 방향(속도 v)을 기억해서 누적한다.
  v = beta * v + 기울기
  p = p - 학습률 * v

효과:
  - 같은 방향으로 계속 가면 가속 (공이 비탈을 굴러내리듯)
  - 좌우로 왔다갔다 하는 진동은 서로 상쇄되어 줄어든다
  => SGD의 진동 문제를 완화.

  (beta 는 보통 0.9 — 이전 속도를 90% 유지한다는 의미)


----------------------------------------------------------------
3. Adam: 파라미터마다 학습률 자동 조정 (핵심)
----------------------------------------------------------------

이름: Adaptive Moment Estimation (적응형 모멘트 추정).
두 가지를 동시에 추적한다.
  m = 기울기의 평균        (1차 모멘트 = 방향, Momentum 역할)
  v = 기울기 제곱의 평균    (2차 모멘트 = 그 파라미터가 얼마나 출렁였나)

  m = b1*m + (1-b1)*g
  v = b2*v + (1-b2)*g^2
  편향 보정:  m_hat = m/(1-b1^t),  v_hat = v/(1-b2^t)
  업데이트:   p = p - 학습률 * m_hat / (sqrt(v_hat) + eps)

핵심 아이디어:
  많이 출렁인 파라미터(v 큼)  -> 학습률을 자동으로 줄임
  잠잠한 파라미터(v 작음)     -> 학습률을 키움
  => SGD가 못 했던 '파라미터별 맞춤 학습률'을 실현.

표준 기본값 (거의 항상 이대로 씀):
  beta1 = 0.9    (방향 평균)
  beta2 = 0.999  (출렁임 평균)
  eps   = 1e-8   (0으로 나누기 방지용 아주 작은 수)

편향 보정(bias correction)이 필요한 이유:
  m, v 는 0에서 시작하므로 초반 몇 스텝은 실제보다 작게 잡힌다.
  (1-b^t) 로 나눠 초반 과소추정을 바로잡는다.


----------------------------------------------------------------
4. AdamW: Adam + Weight Decay (이번 회차의 결론)
----------------------------------------------------------------

Adam 에 'weight decay'를 더한 것.

weight decay 란?
  가중치를 매 스텝 조금씩 0쪽으로 끌어당기는 장치.
  가중치가 너무 커지는 것을 막아 '과적합'을 방지한다.
  (Day 38-39에서 배운 그 과적합. 가중치가 작으면 모델이
   단순해져 새 데이터에도 잘 일반화된다.)

AdamW 논문의 핵심 (이름의 'W' = decoupled Weight decay):
  기존 Adam은 weight decay를 '기울기에 섞어' 넣었다.
  그러면 Adam의 적응형 학습률이 decay 효과를 왜곡시킨다.
  AdamW는 weight decay를 기울기와 '분리(decoupled)'해서
  가중치에 직접 적용한다:

    p = p - 학습률*(m_hat/(sqrt(v_hat)+eps))  -  학습률*wd*p
            └─────── Adam 업데이트 ───────┘     └ 분리된 decay ┘

  이 작은 차이 덕분에 일반화 성능이 좋아졌고,
  LLM 파인튜닝에서 사실상 표준 옵티마이저가 되었다.

weight decay(wd) 효과 (코드 실험 결과):
  wd = 0.0  -> 최종 |가중치| = 0.286
  wd = 0.01 -> 최종 |가중치| = 0.257
  wd = 0.1  -> 최종 |가중치| = 0.040
  => wd가 클수록 가중치가 0쪽으로 더 강하게 당겨진다.
     보통 0.01 정도를 표준으로 쓴다.


----------------------------------------------------------------
5. 왜 이걸 알아야 하나 (실전 연결)
----------------------------------------------------------------

LLM 파인튜닝 코드에는 거의 항상 AdamW가 등장하고,
손봐야 할 '손잡이(하이퍼파라미터)'가 두 개 있다.

  learning rate (학습률):
     보폭. 너무 크면 발산, 너무 작으면 느림. (Day 40-41 내용)

  weight decay:
     과적합 억제 강도. 보통 0.01.

옵티마이저 원리를 모르면 이 두 값을 '왜, 어떻게' 조절하는지
감이 안 온다. "AdamW 쓰세요"를 그냥 따라하는 게 아니라
이해하고 튜닝하기 위해 배운다.


----------------------------------------------------------------
6. 보충: lr_scheduler (학습률 스케줄러)
----------------------------------------------------------------

학습이 진행될수록 학습률을 점점 줄이는 기법.
  초반: 크게 움직여 빠르게 접근
  후반: 보폭을 줄여 골짜기에 정밀하게 안착

LLM 파인튜닝에서 AdamW와 거의 항상 짝으로 쓴다.
(흔한 형태: warmup으로 서서히 올렸다가 -> 서서히 decay)
이번 핵심에서는 곁가지라 코드에는 넣지 않았다.


----------------------------------------------------------------
한눈 정리표
----------------------------------------------------------------

  SGD       같은 학습률          느리고 진동
  Momentum  관성(이전 방향 기억)  진동 억제 + 가속
  Adam      파라미터별 학습률      적응형, b1=0.9 b2=0.999
  AdamW     Adam + 분리된 decay   과적합 방지, 파인튜닝 표준
