가중치를 옮기는 것이 '학습'이다.


----------------------------------------------------------------
1. 손실함수(Loss Function)란?
----------------------------------------------------------------

모델의 예측이 정답과 얼마나 틀렸는지를 '숫자 하나'로 표현하는 함수.

  손실 큼   = 많이 틀림 (나쁨)
  손실 작음 = 잘 맞춤   (좋음)
  손실 = 0  = 완벽

학습의 목표 = 이 손실을 최소화하는 가중치를 찾는 것.

문제 종류에 따라 쓰는 손실이 다르다:
  - 회귀(숫자 예측)  -> MSE
  - 분류/언어모델    -> Cross-Entropy


----------------------------------------------------------------
2. MSE (Mean Squared Error) — 회귀의 손실
----------------------------------------------------------------

      MSE = (1/N) * sum (예측 - 정답)^2

  - 오차를 제곱하는 이유:
      * 부호 제거 (음수 오차와 양수 오차가 상쇄되지 않게)
      * 큰 오차에 더 큰 벌점 (제곱이라 멀수록 급격히 커짐)
  - 회귀(숫자를 맞추는 문제)의 표준 손실.
  - 예) 집값 예측, 온도 예측, 키 예측.

예시:
  정답:      [3, 5, 7, 9]
  좋은 예측: [3.1, 4.9, 7.2, 8.8]  -> MSE 작음 (정답에 가까움)
  나쁜 예측: [1, 8, 4, 12]         -> MSE 큼   (많이 빗나감)


----------------------------------------------------------------
3. Cross-Entropy — 분류 / 언어모델의 손실
----------------------------------------------------------------

분류 문제에서 모델은 '각 클래스일 확률'을 출력한다.
Cross-Entropy는 정답 클래스에 얼마나 높은 확률을 줬는지 평가.

      Loss = -log(정답 클래스의 예측 확률)

  정답 확률      Cross-Entropy
  -----------------------------
      0.99           0.0101
      0.80           0.2231
      0.50           0.6931
      0.20           1.6094
      0.05           2.9957

  - 정답에 확률 1.0  -> -log(1) = 0      (완벽)
  - 정답 확률이 낮을수록 -> 손실이 급격히 커짐
  - 정답 확률 -> 0   -> 손실 -> 무한대

LLM은 '다음 토큰 분류기'라서 이 손실로 학습한다.
('안녕' 다음에 '하세요'가 올 확률을 높이도록 가중치를 조정)


----------------------------------------------------------------
4. 경사하강법(Gradient Descent)
----------------------------------------------------------------

손실을 줄이는 가중치를 어떻게 찾나? -> 기울기를 따라 내려간다.

비유: 안개 낀 산에서 골짜기로 내려가기
  1) 발밑 경사(기울기)를 느낀다
  2) 가장 가파른 내리막 방향으로 한 걸음
  3) 반복하면 골짜기(최저 손실)에 도착

업데이트 공식:
      가중치 <- 가중치 - 학습률 * 기울기

  기울기(gradient) = 손실이 가장 빨리 '커지는' 방향
  -> 그 반대(빼기)로 가면 손실이 '줄어든다'

MSE의 기울기 (미분으로 유도):
   dL/dw = (1/N) sum 2(wx+b - y)*x
   dL/db = (1/N) sum 2(wx+b - y)

y=2x+1, w=0,b=0, lr=0.01 로 한 걸음씩:
  step 0: MSE 57.00
  step 1: MSE 33.23
  step 2: MSE 19.65
  ... 한 걸음마다 줄어든다 (산을 내려가는 중)


----------------------------------------------------------------
5. 학습률(Learning Rate) 실험 ★ 핵심
----------------------------------------------------------------

학습률 = 한 걸음의 크기.

같은 데이터(y=2x+1), 같은 시작점(w=0,b=0)에서 학습률만 바꾼 결과:

[lr = 0.001]  너무 작음 (느림)
  step    1: w=0.0500 b=0.0140 MSE=54.335896
  step   50: w=1.4742 b=0.4158 MSE=5.226091
  step 1000: w=2.0818 b=0.7046 MSE=0.015883
  => 1000걸음을 가도 아직 도착 못함. 보폭이 너무 작다.

[lr = 0.01]  적정 (좋음)
  step    1: w=0.5000 b=0.1400 MSE=33.229600
  step   10: w=1.9688 b=0.5602 MSE=0.286503
  step 1000: w=2.0039 b=0.9860 MSE=0.000036
  => 깔끔하게 골짜기 도착 (w~2, b~1).

[lr = 0.1]  너무 큼 (발산)
  step    1: w=5.0000   b=1.4000   MSE=106.36
  step   10: w=-45.82   b=-12.56   MSE=29232.2
  step   50: 숫자 폭발 -> 발산
  => 골짜기를 건너뛰고 반대편 벽으로 튀어오름.
     걸음마다 더 멀어져 숫자가 무한대로 폭발(발산).

결론:
  너무 작으면 -> 영원히 못 내려감 (느림)
  너무 크면   -> 계곡을 건너뛰고 발산 (폭발)
  => 학습률은 '너무 작지도 크지도 않게' 맞추는 게 핵심.

  주의: '적정 학습률'은 데이터 스케일에 따라 다르다.
        위 0.1은 이 데이터에선 너무 크지만, 다른 데이터에선
        적정일 수도 있다. 항상 실험으로 찾는다.


----------------------------------------------------------------
6. Batch vs Mini-batch vs SGD
----------------------------------------------------------------

차이 = '기울기를 데이터 몇 개로 계산하느냐'.

[Batch GD] 전체 데이터로 기울기 계산 후 한 번 업데이트
  + 안정적이고 정확한 방향
  - 데이터 많으면 한 걸음이 너무 느리고 무거움

[SGD (Stochastic GD)] 데이터 1개로 기울기 계산, 매번 업데이트
  + 매우 빠르고 자주 업데이트
  - 방향이 들쭉날쭉(노이즈) -> 단, 그 덕에 얕은 골짜기 탈출에 도움

[Mini-batch] 일부(4, 32, 256개...)로 계산 -> 둘의 절충
  + 적당히 안정적 + 적당히 빠름 + GPU 효율 좋음
  => 실무 딥러닝의 표준 (보통 배치 크기 32~256)

12개 데이터(y=2x+1), 200 epoch, lr=0.005 결과:
  Batch        -> w~2.06 b~0.52 (수렴 중)
  SGD(1개)     -> w~2.00 b~1.00 (정확히 수렴)
  Mini-batch(4)-> w~2.02 b~0.79 (수렴 중)

=> 세 방식 모두 같은 골짜기(w~2,b~1)로 수렴한다.
   '가는 길'이 다를 뿐 도착지는 같다.
   SGD/미니배치는 업데이트가 잦아 큰 데이터에서 훨씬 빠르다.


----------------------------------------------------------------
7. 전체 흐름 한눈에
----------------------------------------------------------------

  손실함수          -> 예측이 정답과 얼마나 틀렸나 (숫자 하나)
  MSE              -> 회귀의 손실 = 평균 (예측-정답)^2
  Cross-Entropy    -> 분류/언어모델의 손실 = -log(정답확률)
  경사하강법         -> 기울기 반대로 한 걸음씩 (산 내려가기)
  학습률            -> 걸음 크기 (작으면 느리고 크면 발산)
  Batch/SGD/미니배치 -> 기울기를 데이터 몇 개로 계산하느냐

한 줄 요약:
  손실을 정의하고(MSE/CE), 그 기울기를 따라(경사하강법),
  적절한 보폭으로(학습률) 가중치를 옮기는 것이 '학습'이다.
