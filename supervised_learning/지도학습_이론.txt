================================================================
 Day 38-39 : 머신러닝이란? — 지도학습의 원리 (이론 정리)
================================================================

이 문서는 코드(main.rs)와 짝을 이루는 이론 정리본입니다.
코드를 돌리지 않아도 개념을 읽을 수 있도록 정리했습니다.


----------------------------------------------------------------
1. 머신러닝이란 무엇인가
----------------------------------------------------------------

핵심은 "전통적 프로그래밍"과 "머신러닝"의 방향이 반대라는 점.

  [전통적 프로그래밍]
     규칙(코드) + 입력  ->  출력
     사람이 "어떻게 푸는지"를 직접 다 적는다.
     예) if 온도 > 28 { "더움" } else { "안 더움" }

  [머신러닝]
     입력 + 출력(정답)  ->  규칙(모델)
     정답 예시만 잔뜩 주면, 기계가 입력->출력 규칙을 스스로 찾는다.

정의:
  머신러닝 = "데이터로부터 패턴(규칙)을 학습하는 알고리즘"
  사람이 규칙을 짜는 게 아니라, 데이터가 규칙을 만든다.


----------------------------------------------------------------
2. 지도학습 vs 비지도학습
----------------------------------------------------------------

[지도학습 (Supervised Learning)]
  - 입력 x 와 정답 y 가 '쌍'으로 주어진다.  (x, y)
  - 모델이 x -> y 관계를 배운다.
  - 두 종류:
      * 분류(Classification): 정답이 카테고리 (개/고양이, 스팸/정상)
      * 회귀(Regression):     정답이 숫자     (집값, 온도, 키)
  - 예) 사진(x) -> "고양이"(y),  평수(x) -> 집값(y)

[비지도학습 (Unsupervised Learning)]
  - 정답 y 가 없다. 입력 x 만 있다.
  - 데이터 속 '숨은 구조'를 스스로 발견한다.
  - 예) 군집화(비슷한 고객 묶기), 차원 축소

** LLM 파인튜닝은 지도학습이다. **
   instruction(입력) -> response(정답) 쌍으로 가중치를 조정한다.


----------------------------------------------------------------
3. 가중치(Weight)와 편향(Bias)
----------------------------------------------------------------

모델은 결국 '입력을 출력으로 바꾸는 함수'다.
가장 단순한 형태가 직선:

      y = w*x + b

  w (weight, 가중치): 직선의 기울기. 입력이 출력에 주는 영향력.
  b (bias, 편향):     직선의 y절편.  기본적으로 깔고 가는 값.

같은 입력 x=3 이라도 w, b 에 따라 출력이 달라진다:
  w=1, b=0  -> y = 3
  w=2, b=0  -> y = 6
  w=2, b=1  -> y = 7
  w=0.5,b=5 -> y = 6.5

학습이란 = 데이터에 가장 잘 맞는 (w, b) 를 찾는 것.
이 w, b 를 '학습되는 파라미터(parameter)'라고 부른다.
LLM은 이 파라미터가 수십억~수천억 개일 뿐, 원리는 똑같다.


----------------------------------------------------------------
4. 손실(Loss) — '얼마나 틀렸나'를 숫자로
----------------------------------------------------------------

"잘 맞는다"를 숫자로 재는 도구가 손실 함수(Loss).

회귀에서 가장 흔한 손실: 평균제곱오차 (MSE)

      MSE = (1/N) * sum (예측값 - 정답)^2

  - 예측 = 정답  -> 오차 0 -> MSE 0 (완벽)
  - 멀어질수록   -> 제곱이라 손실이 급격히 커짐
  - 제곱하는 이유: 부호 제거 + 큰 오차에 더 큰 벌점

실습 데이터의 진짜 관계는  y = 2x + 1.
여러 (w,b)를 넣어 손실을 관찰하면:

     w     b        MSE
  ----------------------
   0.0   0.0     57.0000
   1.0   0.0     18.0000
   2.0   0.0      1.0000
   2.0   1.0      0.0000   <- 완벽! (진짜 정답)
   3.0   1.0     11.0000
   2.0   2.0      1.0000

관찰: 정답 (w=2, b=1)에서 MSE=0. 멀어질수록 손실이 빠르게 커진다.
      => 학습 = 이 MSE를 가장 작게 만드는 (w,b) 찾기.


----------------------------------------------------------------
5. 경사하강법(Gradient Descent) — 자동으로 정답 찾기
----------------------------------------------------------------

사람이 (w,b)를 일일이 넣어보는 건 비효율적이다.
기계는 '기울기(gradient)'로 자동으로 정답을 찾아간다.

  1) 손실 L 을 w, b 로 편미분 -> 기울기 (dL/dw, dL/db)
  2) 기울기는 'L이 가장 빨리 커지는 방향'.
     => 그 반대로 가면 L이 줄어든다.
  3) 업데이트:
        w <- w - (학습률 * dL/dw)
        b <- b - (학습률 * dL/db)
  4) 1~3 반복 -> 손실이 점점 줄어 최저점 도달.

MSE의 기울기 (미분으로 유도):
   dL/dw = (1/N) sum 2(wx+b - y)*x
   dL/db = (1/N) sum 2(wx+b - y)

w=0, b=0 에서 시작, 학습률 0.01 로 돌린 결과:

     step          w          b          MSE
  --------------------------------------------
        1     0.5000     0.1400    33.229600
       10     1.9688     0.5602     0.286503
      100     2.0818     0.7048     0.015866
      500     2.0211     0.9238     0.001056
     1000     2.0039     0.9860     0.000036
     2000     2.0001     0.9995     0.000000

=> 백지 상태(w=0,b=0)에서 시작해도, 손실을 줄이는 방향만
   따라가면 기계가 스스로 y=2x+1 을 찾아낸다. 이것이 '학습'.
   (경사하강법은 모든 딥러닝 학습의 엔진이다.)


----------------------------------------------------------------
6. 과적합(Overfitting)과 일반화(Generalization)
----------------------------------------------------------------

학습의 진짜 목표는 '훈련 데이터 암기'가 아니라
'본 적 없는 새 데이터에도 잘 맞추기' = 일반화.

[과적합 Overfitting]
  훈련 데이터에는 완벽(노이즈까지 외움)하지만,
  새 데이터에는 형편없는 상태.
  => "기출문제만 통째 외운 학생". 변형 문제에 0점.

[원인]
  - 모델이 너무 복잡 (데이터 대비 파라미터 과다)
  - 데이터가 너무 적음
  - 너무 오래 학습

[탐지 신호]
  훈련 손실은 계속 낮아지는데, 검증 손실은 어느 순간부터 올라간다.
  => 그 지점이 "외우기 시작한" 순간.

학습 곡선 모양:
  훈련 손실:  높음 --------> 계속 낮아짐
  검증 손실:  높음 --> 낮아짐 --> (!) 다시 올라감
                            ^
                      여기서 멈춰야 함 (조기 종료)

[막는 방법]
  더 많은 데이터, 단순한 모델, 조기 종료(early stopping),
  정규화(regularization), 드롭아웃(dropout) 등.


----------------------------------------------------------------
7. 훈련 / 검증 / 테스트 세트 분리
----------------------------------------------------------------

과적합을 '탐지'하려면 모델이 본 적 없는 데이터로 평가해야 한다.
그래서 데이터를 셋으로 나눈다.

  훈련 세트 (Train, ~70%):
     모델 학습에 사용. 가중치가 이 데이터로 조정된다.

  검증 세트 (Validation, ~15%):
     학습 중간 점검 + 설정(학습률 등) 튜닝.
     "언제 멈출지", "어떤 모델이 나은지" 결정.

  테스트 세트 (Test, ~15%):
     학습이 다 끝난 뒤 '딱 한 번' 쓰는 최종 시험.
     학습/튜닝에 절대 쓰면 안 된다 (정직한 성적표).

왜 나누나?
  훈련 데이터로 평가 = 외운 걸 그대로 묻기 -> 실력 과대평가.
  본 적 없는 데이터로 평가해야 진짜 '일반화 능력'이 보인다.

철칙:
  테스트 세트는 학습/튜닝에 절대 쓰지 않는다.
  (한 번이라도 보면 더 이상 '공정한 시험'이 아니다.)


----------------------------------------------------------------
8. LLM 파인튜닝과의 연결
----------------------------------------------------------------

오늘 배운 개념이 LLM 파인튜닝에 그대로 적용된다.

  지도학습        -> instruction(입력) -> response(정답) 쌍으로 학습
  가중치/편향     -> 모델 파라미터 (LLM은 수십억 개)
  손실 함수       -> cross-entropy (Day 35): 예측이 정답과 얼마나 다른가
  경사하강법      -> 손실을 줄이는 방향으로 가중치 업데이트
  과적합          -> 특정 데이터만 외워 새 질문에 약해짐
  train/val/test  -> 파인튜닝 데이터도 동일하게 분리

한 줄 요약:
  머신러닝 = 정답 예시(데이터)로 손실을 줄여가며 가중치를 조정해,
            새 데이터에도 잘 맞추게 만드는 것.

----------------------------------------------------------------

train / val / test (데이터 분리)
MSE(평균제곱오차)     gradient descent(경사하강법)
